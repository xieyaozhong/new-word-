# 掌上魚缸

在手機上養魚的網頁小遊戲：餵魚、收金幣、配對繁殖、收集基因和稀有色、派魚去附近的河流湖泊探險，還有外星訪客、水草生命週期、季節水溫等系統。

**開始玩：** https://xieyaozhong.github.io/new-word-/

本次擴充加入 12 種魚、6 種小生物、3 位 NPC 的 9 章故事，以及 4 種每日事件。水族店的「新夥伴」可購買新增生物；圖鑑支援名稱、英文代號與關鍵字搜尋，並可依生物種類和收集狀態篩選。

水族店的「魚缸」可開設多個獨立魚缸，最多共 5 缸。第 2～5 缸分別售價 50,000、100,000、200,000、400,000 金幣，不參加折扣。每缸獨立保存生物、設備、造景、水質、魚卵與探險；金幣、道具、圖鑑和任務共用。可命名、切換魚缸，並從生物資料頁搬缸。舊存檔會自動成為第一缸。

- 整個遊戲是一個檔案：`index.html`，不需要安裝或建置。
- 遊戲進度存在瀏覽器裡（localStorage），換手機或清除瀏覽器資料會重新開始。
- 在 Claude 裡開啟時才有的功能（雲端存檔、用 AI 產生你所在地區的探險地圖）在這個網頁版不會出現，探險會使用內建的台中示範地圖。

本機開發可用 `python -m http.server 8765` 預覽。執行 `node scripts/validate-game.cjs` 可檢查物種、故事、每日事件、搜尋，以及多魚缸購買、搬魚與存檔相容性；不需安裝額外套件。
