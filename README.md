# 掌上魚缸

在手機上養魚的網頁小遊戲：餵魚、收金幣、配對繁殖、收集基因和稀有色、派魚去附近的河流湖泊探險，還有外星訪客、水草生命週期、季節水溫等系統。

**開始玩：** https://xieyaozhong.github.io/new-word-/

先前擴充加入 12 種魚、6 種小生物、3 位 NPC 的 9 章故事，以及 4 種每日事件。新增生物會輪替出現在水族店。圖鑑支援名稱、英文代號與關鍵字搜尋，並可依生物種類和收集狀態篩選。

水族店「造景」每期輪賣 4 件擺設和 2 款魚缸背景。兩次擴充共加入 18 件擺設與 9 款背景，和舊款一起輪替。本次的背景有巨藻森林、暮色棧橋、月下石林、海玻璃灣與水沒書庫，擺設包括木雕白鷺、航海星象儀、潮汐沙漏與水底唱機。每天本地時間午夜換貨，使用時空加速器也會換到下一批。毬藻、青龍石、陶罐與沉木常駐。擺設只放在購買時所在的魚缸，背景則只需購買一次，就能隨時在不同缸各自換上。

水族店的「魚缸」可開設多個獨立魚缸，最多共 5 缸。第 2～5 缸分別售價 50,000、100,000、200,000、400,000 金幣，不參加折扣。每缸獨立保存生物、設備、造景、水質、魚卵與探險；金幣、道具、圖鑑和任務共用。可命名、切換魚缸，並從生物資料頁搬缸。舊存檔會自動成為第一缸。

- 遊戲主程式是 `index.html`，搭配 `sw.js`、`pwa-updates.js` 提供離線使用與自動更新，不需要建置。
- 遊戲進度存在瀏覽器裡（localStorage）。換裝置或清除資料前，請先從「魚兒 › 存檔與更新」下載備份。
- 在 Claude 裡開啟時才有的功能（雲端存檔、用 AI 產生你所在地區的探險地圖）在這個網頁版不會出現，探險會使用內建的台中示範地圖。

本機開發可用 `python -m http.server 8765` 預覽。執行 `node scripts/validate-game.cjs` 可檢查物種、故事、每日事件、搜尋，以及多魚缸購買、搬魚與存檔相容性；不需安裝額外套件。

PWA 會在開啟、切回前景、恢復連線及使用期間定期檢查更新。新版準備好後，先確認本機存檔成功，再重新載入；活動、交易和存檔轉移期間會延後更新。離線時繼續使用已下載的版本。已安裝的舊版請連線後關閉並重新開啟一次，以取得這次的自動更新機制。

分頁與 PWA 若共用儲存空間，會沿用同一份進度。若 PWA 顯示新遊戲，請在原分頁的「魚兒 › 存檔與更新」下載 JSON 檔或複製存檔文字，再到 PWA 同一頁選擇檔案或貼上文字、檢查內容、確認載入。載入會取代進度，不會合併兩份存檔；匯入前的進度會保留，可用「還原匯入前備份」復原。多視窗共用進度時，由最後開啟的視窗接手，舊分頁會暫停，避免覆蓋新的進度。

自動更新驗證可執行 `node scripts/validate-pwa.cjs`。發布新版時請同步更新 HTML 的 `application-version`、`APP_BUILD` 與 service worker 的版本識別。深海生物與巨獸的造型參考記錄在 [建模資料來源](docs/abyss-model-references.md)。
